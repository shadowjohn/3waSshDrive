# 3waSshDrive

Project a Linux workspace into Windows as a drive letter through WinFsp and SFTP—without shelling out to SSHFS-Win, `net use`, or `cmd.exe`.

Phase 1 is under active development. See the [design](docs/superpowers/specs/2026-09-18-phase1-mount-skeleton-design.md) and [implementation plan](docs/superpowers/plans/2026-09-18-phase1-mount-skeleton.md).
